# 🎵 SoundWave: Master Full-Stack Architecture & Engineering Prompt

Is prompt ko aap kisi bhi AI Agent ya developer ko dekar poora **SoundWave** project scratch se reproduce ya aage scale karwa sakte hain.

---

```markdown
You are an expert Principal Full-Stack Engineer and AI Systems Architect. Build "SoundWave", an ultra-modern, high-performance, ad-free entertainment web app, PWA, and future native Android APK. 

The app combines Spotify-style lossless music streaming, YouTube-style high-definition video lounge, and Netflix-style 1080p cinema streaming with 100% free-tier architecture, zero third-party trademark infringement, and bulletproof DMCA safe harbor protections.

---

### 1. CORE ARCHITECTURE & TECH STACK
- **Backend Server:** Lightweight, high-concurrency Python server (`ThreadingHTTPServer`) with zero heavy framework overhead, running on port 5000.
- **Media Engines:** 
  - `yt-dlp` integrated with local Node.js JavaScript runtime for rapid 0.2-second stream resolution without rate-limiting.
  - `ffmpeg` for audio conversion and direct stream extraction.
  - Custom web scrapers for public cinema indexes (1080p movies with trailers, metadata, cast, ratings).
- **Frontend Stack:** Modern, high-performance Vanilla JavaScript, modular CSS3 with GPU-accelerated transitions, and semantic responsive HTML5.
- **PWA (Progressive Web App):** Service Worker (Network-First strategy with auto-cache-busting) and `manifest.json` for 1-click mobile phone home-screen installation without requiring desktop mode.

---

### 2. COPYRIGHT SHIELD & WHITE-LABEL CLOAKING (ZERO STRIKE RISK)
- **Zero Third-Party Trademarks:** 
  - Strictly NO mentions of "YouTube", "Spotify", or "Vegamovies" in public UI, titles, placeholders, meta tags, or network responses.
  - Rebranded as:
    - YouTube Videos ➔ **"SoundWave Videos"** (Emerald gradient play logo).
    - Spotify Style ➔ **"SoundWave VIP / Lossless Audio"**.
    - Vegamovies ➔ **"Cinema HD (1080p) / Cinema Vault"**.
- **DMCA Safe Harbor Compliance (17 U.S.C. § 512):**
  - Dedicated "DMCA & Legal" sidebar button and detailed legal modal.
  - Explicit safe-harbor clauses confirming SoundWave is a media search indexer that does not host, upload, or own copyrighted files.
  - Designated takedown email: `copyright@soundwave.app`.
- **Permanent Caching & Chunk Retention:**
  - Preserve downloaded streaming chunks and media files on disk for instant 0-second repeat playback without re-buffering or burning user bandwidth.

---

### 3. ADVANCED ENTERTAINMENT FEATURES
1. **Instant 0.2s Video Streaming (Zero-Buffering Engine):**
   - Direct high-speed streaming without waiting for server-side re-encoding or merging. Video starts playing in under 0.2 seconds in 1080p full HD.
2. **High-Views / Viral Internet Hits Section:**
   - Prominent grid displaying viral trending songs with internet view badges (`🔥 850M+ Views`, `⭐ 1.2B Views`, `💥 420M Views`, `1080p HD`).
   - Endless Browse System: A prominent `Browse More Trending Songs ▾` button that dynamically loads subsequent batches of global and regional viral hits.
3. **✨ Dynamic Ambient Glow Mode:**
   - Real-time neon radial glow behind the video theater stage matching the video/song theme, toggleable via `✨ Glow: ON/OFF`.
4. **♾️ Infinite Autoplay Queue ("Up Next" Engine):**
   - When a track or video reaches the end of its playlist, automatically query related songs by artist and genre, appending fresh recommendations so playback never stops.
5. **⧉ Picture-in-Picture (PiP / Floating Mini-Player):**
   - Native browser PiP and in-app floating mini-player docked at the bottom-right. When users navigate to Home, Movies, Sports, or Library while a video is playing, it automatically floats and continues playback seamlessly.
6. **⚡ Playback Speed Controller:**
   - Cycle through `0.75x`, `1.0x`, `1.25x`, `1.5x`, and `2.0x` speeds for both video and bottom audio player bars with pitch preservation.
7. **🎬 Cinema HD & ⚽ Sports Categories:**
   - Dedicated sidebar tabs and top horizontal category filter chips for `Trending`, `🎬 Movies`, `⚽ Sports`, `Arijit Singh`, `Punjabi Hits`, `Bollywood 4K`, etc.

---

### 4. 100% FREE PRODUCTION ROADMAP (MONETIZATION & APK)
- **Database & Auth:** Firebase Spark Plan / Supabase (100% Free forever up to 50k monthly active users) for user accounts, liked songs, and subscription flags.
- **Payment Gateway (Zero Setup Cost):**
  - Direct Dynamic UPI QR Code (0% transaction fee, instant settlement for India).
  - Razorpay / Cashfree Free Sandbox test mode for subscription checkout.
- **Mobile APK Conversion:**
  - Use Capacitor to package the existing HTML/CSS/JS shell into a signed native Android APK with lock-screen notification media controls and background audio playback.
```
